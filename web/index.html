One owned environment

The template creates a Foundry account, three model deployments, AI Gateway Consumption, and monitoring resources for this playground.

The Python app runs locally over HTTPS. It sends prepared requests through the gateway and displays their recorded evidence.

Experiment path

  1. Check model access with valid and rejected credentials.
  2. Route one alias across three models with weights and priorities.
  3. Test a request limit without blocking the normal alias.
  4. Call the model through an OpenAPI-generated MCP tool.
  5. Inspect native request spans, token counters, and estimated model cost.

Run Check Setup after configuration. Reset clears local evidence and restores weighted routing; it does not delete resources or logs.
